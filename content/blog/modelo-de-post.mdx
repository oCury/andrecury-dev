Cada texto é um arquivo `.mdx` nesta pasta. O nome do arquivo vira o endereço: `meu-texto.mdx` aparece em `/blog/meu-texto`.

## O frontmatter

O bloco entre as linhas `---` é o frontmatter. `titulo`, `data` (AAAA-MM-DD) e `resumo` são obrigatórios; `tags` é opcional. Com `rascunho: true` o texto só aparece no computador de quem escreve.

## O corpo

Markdown comum: **negrito**, *itálico*, [links](https://andrecury.dev.br), listas, tabelas e blocos de código.

> Uma citação fica assim.
